# Ta-KI

Ein Skill für Claude: Im Ta-KI-Modus gibt Claude jede Antwort 3 bis 6 Mal, jedes Mal leicht anders formuliert, mit
demselben Sinn.

## Installieren

Den Ordner `ta-ki` nach `~/.claude/skills/` kopieren (für alle Projekte) oder nach `.claude/skills/` in einem Projekt.

    cp -r ta-ki ~/.claude/skills/

## Benutzen

- Einschalten: `/ta-ki` oder „Ta-KI-Modus“
- Ausschalten: „Ta-KI aus“
